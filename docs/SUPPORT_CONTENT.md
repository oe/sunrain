# Sunrain 站内自助与求助内容交付

当前候选版本已按产品走查补齐：近况梳理有两组问题的进度与真实跳过按钮；结果优先展示一个可选行动，原始回答仍完整保留。推荐行动可在结果页内逐步完成，所选例子、小计划和反馈可在用户主动准备求助时补入沟通摘要，避免跨页丢失或额外持久化。独立自助页也支持同页准备。完整声明保留在八语使用边界页和可展开说明内。

普通求助先选地区，再准备消息，六步预约说明按需展开。运行目录见 [support-services.json](../src/data/support-services.json)：覆盖英格兰、美国、日本、韩国、西班牙、香港的官方入口，以及北京一家医院自身的挂号指引，不能解释为中国全国或全球覆盖。联系模板使用自然的开场白与非空字段段落，支持主动复制、下载与保存。危机目录失效时保留紧急服务路径，普通预约明确作为非紧急的独立入口。

更新日期：2026-10-19。本文补充 [入口规格](./MENTAL_HEALTH_CHECK_IN.md)，定义用户点进每个出口后能读到和完成什么。配套的 [八语完整内容草案](./content/support-copy.json) 已写入仓库，状态为待专业、母语及权利核验；该草案保留为设计记录。当前运行内容在 [src/data/support-copy.json](../src/data/support-copy.json)，已接入八语页面，并增加睡眠与担忧行动；代码实现不表示已上线或完成专业审阅。

## 2. 八语内容包

语言完整覆盖 `en`、`zh-hans`、`zh-hant`、`es`、`ja`、`ko`、`hi`、`ar`。各语言具有相同内容字段：

- 入口文案及完整免责声明。
- 结果解释、低分、未完成、未覆盖等状态说明及自主选择支持的提示。
- 两段自助行动的目的、四个步骤和可带走的结果。
- 不舒服、没有变化、结束与保存的处理说明。
- 一般求助六个步骤、可复制预约模板及五项沟通摘要。
- 费用、候诊、地区未覆盖或链接失败、已有照护团队时的处理说明。

这些是 Sunrain 编写的教育与产品文案草案，不是 WHO、NHS 或 NIMH 的官方译本，也不表示经过其认证。方法参考与使用条件见 [E10 至 E15](./CLINICAL_EVIDENCE.md#e10-感官练习参考)。所有语言的专业和母语审阅状态仍为未完成。

八语完整流程是发布目标。每个已开放的语言必须具备完整声明、结果说明、行动、失败处理和求助指引。不能将英语回退算作覆盖；某语言尚未完成时明确状态，不让用户开始一个无法用该语言完成的评估流程，也不影响其直接获取已可用的资源。

## 3. S01 感官练习

计划路径：`/self-help/grounding/`。用户按当前需要主动选择；不得因某个疾病分数自动规定必须完成。

1. **开始前**：说明是压力当下的短暂支持，不能代替治疗；可随时停止，可保持睁眼，感官不适用时可跳过。
2. **逐步进行**：注意五样可见的东西、四种触感、三种声音、两种气味和一种已经存在的味道；不要求寻找或品尝物品。
3. **完成后**：可留下一个帮助自己重新留意周围的细节；也可以什么都不保存。
4. **反馈与出口**：有帮助时可结束或主动保存；没变化时可换方式或准备求助；不舒服时立即停止，不显示“再坚持一下”等文案。

来源用于支持方法选择，不证明此段改编适合每个人或具有特定疗效。具体文案和适用条件尚未经独立专业审阅，按一般教育内容提供，不作为治疗课程。[E10](./CLINICAL_EVIDENCE.md#e10-感官练习参考)

## 4. S02 小步骤计划

计划路径：`/self-help/one-step/`。用于日常需要难以开始时的一般自我照顾，不包装为完整行为激活或抑郁治疗课程。

1. **选择需要**：例如一项日常需要、休息或请求实际帮助，不要求先填写病名。
2. **减到可承受**：选一件小事，也可以选择休息、减负或请人协助，不要求增加活动量。
3. **形成计划**：写下做什么、何时可能做、需要谁或什么帮助；留在当前会话或自行选择保存。
4. **回顾**：完成、未完成或改变计划都可结束；不评分、不排名、不因没有行动而责备用户。

产出是具体小计划。若有既定照护计划，按其执行；不能用此卡片替代专业建议。[E11](./CLINICAL_EVIDENCE.md#e11-日常自我照顾参考)

## 5. H01 一般求助全流程

计划路径：`/support/`，包括以下步骤和对应文案。所有步骤均可从结果页直接进入，也可不经评估进入。

### 选择合适的起点

用户自己选择当前国家或地区和希望使用的服务语言。说明当地基层医疗、公立门诊、合格心理健康专业人士可能承担不同角色；不按网页排名或付费赞助暗示专业优劣。

能使用已核验的本地目录时展示机构入口、适用条件、费用信息来源、语言、最近核验日期以及实际渠道。不能将危机热线目录冒充一般诊疗目录。初始目录参考单独记录在 [support-resources.json](./content/support-resources.json)；目前只核对了英格兰与美国的官方查找入口，不宣称全球转介已覆盖。

未覆盖地区、链接不可用或没有找到机构时，保留站内的求助沟通模板和选择服务的检查项，指引联系当地基层医疗或公立医疗服务；明确这一步仍需用户自行联系，不伪造可预约机构。

### 准备第一次联系

无需自我诊断。用户可复制或在自己设备上修改下面的模板，网站不自动发送：

> 我想预约一次心理健康初步评估。我已经有一段时间受到一些困扰，并影响日常生活。请问如何预约、是否需要转介、费用如何、提供哪些语言服务？

可选择补充困扰、持续时间和生活影响。首次联系不强制提供完整量表答案、姓名或详细病史给网站。[E12、E13](./CLINICAL_EVIDENCE.md#e12-首次沟通准备参考)

### 预约前和就诊时

站内提供可跳过的沟通准备单：最困扰的事情、何时开始、生活影响、已尝试的办法、想问的问题。用户可自行决定向专业人士提供用药及既有治疗信息，不上传到 Sunrain。

建议向服务方核实：专业资质、是否适合处理自己的困难、费用和保险、服务语言、无障碍安排、候诊时间及保密规则。可选择由信任的人陪同。服务方给出的具体建议不能由网站自动替代。[E12、E13](./CLINICAL_EVIDENCE.md#e12-首次沟通准备参考)

### 费用、候诊与联系失败

- **费用困难**：询问公立、社区、保险、学校或员工支持等可能渠道；不承诺所有地区都有、不保证免费或同样的保密条件。
- **需要候诊**：问清等待期间的支持和恶化时该联系谁，也可询问其他合适的服务。
- **机构未回复或不接收**：允许记下联系状态、尝试另一机构或回到基层医疗询问转介；不把点击外链记为“已获得照护”。
- **已有专业照护**：优先准备与现有团队沟通的变化和问题，遵循既定计划。
- **有立即危险**：直接转到当地紧急支持说明，不能要求完成自助或等预约。网站没有实时查看回答的工作人员。

求助流程在用户带走准备材料、找到符合自身情况的外部入口并知道如何联系时完成站内交接。预约、接诊、诊断和治疗在相应服务中完成，Sunrain 不显示未经服务方确认的预约成功状态。

## 6. 每个结果出口的去向

| 用户选择或状态 | 站内内容 | 必须提供的后续 |
|---|---|---|
| 想先缓一缓 | S01；可选既有呼吸/声音 | 结束、主动保存、其他支持、H01 |
| 想做一点事情但无从开始 | S02 | 小计划、缩小计划或请求协助、H01 |
| 想知道该找谁或如何开口 | H01 | 地区入口、预约模板、准备单、候诊与失败处理 |
| 已在接受治疗 | H01 的既有照护说明与沟通准备 | 联系现有团队，不自动给新治疗方案 |
| 多个方面有提示、说不清、低分但仍困扰 | 各项结果及覆盖局限；用户自主选 S01/S02/H01 | 不以总分决定有无求助资格 |
| 有关安全的回答 | 单独关怀提示、求助及紧急支持 | 不判断安全、不以历史回答自动判定当下紧急程度 |
| 当前有立即危险 | 紧急支持说明及本地服务 | 直接求助，不要求继续评估或练习 |
| 内容或该语言尚未可用 | 明确说明，保留该语言的一般支持指引 | 用户自主选择可用语言或官方资料；不静默回退 |

## 7. 八语发布验收

对每个开放语言，实际走通首页、说明、适用工具、结果、S01/S02/H01、无变化、不舒服、地区缺失、保存删除、返回入口等路径；阿拉伯语同时检查 RTL、键盘顺序与文本方向。

内容完整性检查和专业审阅分别记录。JSON 具有相同字段，只能证明文案结构完整，不能证明语言准确、医学适用或页面可用。官方目录入口也不表示已实际完成预约。当前已接入八语页面和上述交互，提供七个明确范围的官方入口。按一般教育、自助和求助导航范围发布，保留独立专业与母语审阅未完成的真实状态；真实用户验证、实机测试、翻译纠错和地区入口维护作为持续改进。未来医学筛查功能仍按单独准入条件处理，详见 [RELEASING.md](./RELEASING.md)。
