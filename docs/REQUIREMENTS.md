# Sunrain 需求文档

当前实现与发布边界见 [RELEASING.md](./RELEASING.md)：一般支持流程已接入八语页面；医学评分关闭，独立专业和母语审阅仍待完成。

> 版本: 2.1 | 更新日期: 2026-10-19

本文件描述需求，不代表所有功能已经实现。心理状态初筛与自助入口的详细流程、发布条件和免责声明草案见 [MENTAL_HEALTH_CHECK_IN.md](./MENTAL_HEALTH_CHECK_IN.md)，资料与核验状态见 [CLINICAL_EVIDENCE.md](./CLINICAL_EVIDENCE.md)。

## 1. 项目概述

### 1.1 项目名称
**Sunrain** (🌤️ 晴雨) — "Where the sun meets the rain"

### 1.2 项目愿景
提供开源、免费、注重隐私的心理健康教育与自助支持，帮助用户理解近期困扰、采取可完成的行动，并在需要时寻求现实支持。症状初筛不能用于确认或排除疾病。

### 1.3 目标用户
- 希望了解自身心理健康状态的普通用户
- 需要放松减压的上班族/学生
- 寻找心理危机援助资源的用户
- 关注心理健康但无法/不愿寻求专业帮助的人群

### 1.4 核心价值
| 价值 | 描述 |
|------|------|
| 隐私优先 | 心理健康回答不上传；新流程由用户主动选择本地保存；如实披露托管与 CDN 基础访问处理 |
| 开放可及 | 开源、免费、支持多语言 |
| 有据可查 | 逐项核验工具、语言版本、评分和内容依据，不将原始方法证据等同于网站疗效 |

## 2. 功能需求

### 2.1 首页 (Home)
**目的**: 让用户无需先知道病名就能进入适合的帮助路径

**功能点**:
- [ ] 主 CTA 为“I'm not feeling okay / 我最近不太好”，进入初筛开始说明
- [ ] 告知当前可评估的范围、局限和适用人群，不承诺判断疾病
- [ ] 可直接选择放松或求助，不强制先完成评估
- [ ] 支持浅色/深色主题切换
- [ ] 响应式布局，适配移动端

### 2.2 心理测评 (Assessment)

新流程支持用户选择多个困扰方向，分别完成符合准入条件的工具，并分别解释结果。不将不同量表相加，不输出疾病概率；未完成、未覆盖和不适用须分别说明。PHQ-9/GAD-7 的既有代码仍需完成具体版本、译本、授权及专业审阅核验；APA 多维工具处于候选状态。详见 [工具准入和评分规则](./MENTAL_HEALTH_CHECK_IN.md#4-评估规则)。

#### 2.2.1 测评列表页
**目的**: 展示可用的测评量表和历史记录

**功能点**:
- [ ] 展示所有可用量表（PHQ-9, GAD-7）
- [ ] 显示量表基本信息（名称、描述、题目数、预计时长）
- [ ] 展示历史测评记录
- [ ] 支持清除历史记录

**量表要求**:
| 量表 | 用途 | 题目数 | 时长 |
|------|------|--------|------|
| PHQ-9 | 抑郁症状筛查 | 9 题 | ~5 分钟 |
| GAD-7 | 焦虑症状筛查 | 7 题 | ~3 分钟 |

#### 2.2.2 测评进行页
**目的**: 引导用户完成测评

**功能点**:
- [ ] 单题展示，逐题作答
- [ ] 显示作答进度条
- [ ] 支持上一题/下一题导航
- [ ] 记录用户选择，支持修改
- [ ] 允许退出或跳过整个工具；未完成答卷不计算分数，不把缺失或非法答案当成零
- [ ] 量表按具体语言版本准入，不在答题中悄悄回退语言

#### 2.2.3 测评结果页
**目的**: 展示测评结果和建议

**功能点**:
- [ ] 各量表分别显示症状分数和程度，说明不能确认或排除疾病
- [ ] 使用文字解释程度，不能只依赖颜色，也不将低分表示为安全保证
- [ ] 显示本次覆盖范围、来源、局限和可执行的下一步
- [ ] 显示免责声明
- [ ] 支持自主查看来源、进入合适的自助内容或准备求助；可重新测评但不默认要求重测
- [ ] 多个方向同时有提示时并列解释，不自动认定为多种疾病

**结果等级定义 (以 PHQ-9 为例)**:
| 分数范围 | 等级 | 颜色 |
|---------|------|------|
| 0-4 | 极少抑郁症状 | 绿色 |
| 5-9 | 轻度抑郁症状 | 黄色 |
| 10-14 | 中度抑郁症状 | 橙色 |
| 15-19 | 中重度抑郁症状 | 红色 |
| 20-27 | 重度抑郁症状 | 红色 |

分界依据见 [PHQ-9 原始研究记录](./CLINICAL_EVIDENCE.md#e2-phq-9-原始验证研究)。颜色不是诊断或紧急程度分类，具体语言文案与后续响应另行审阅。

### 2.3 呼吸练习 (Breathing)
**目的**: 提供简单有效的放松工具

**功能点**:
- [ ] 可视化呼吸引导圆环
- [ ] 三阶段循环：吸气 → 屏息 → 呼气
- [ ] 显示完成周期数
- [ ] 可自定义各阶段时长
- [ ] 开始/暂停/重置控制

**默认参数**:
- 吸气: 4 秒
- 屏息: 4 秒
- 呼气: 4 秒

### 2.4 危机热线 (Crisis)
**目的**: 为需要帮助的用户提供专业求助渠道

**功能点**:
- [ ] 按国家/地区组织热线信息
- [ ] 显示热线名称、电话、服务时间、支持语言
- [ ] 可点击电话号码直接拨打
- [ ] 支持搜索和筛选
- [ ] 紧急情况提示

**数据要求**:
- 覆盖 30+ 国家/地区
- 包含热线名称、电话、网站、服务时间、支持语言
- 根据当前语言优先显示相关国家

### 2.5 关于页面 (About)
**目的**: 介绍项目背景和重要声明

**功能点**:
- [ ] 项目使命介绍
- [ ] 核心价值展示
- [ ] 免责声明
- [ ] 开源信息和链接

### 2.6 自助行动与一般求助

交付内容和所有结果出口见 [SUPPORT_CONTENT.md](./SUPPORT_CONTENT.md)；八语完整文案草案见 [support-copy.json](./content/support-copy.json)。当前缺少对应运行页面，不能作为已完成功能。

**目的**: 让用户在初筛后完成一个行动，或带走可用于现实求助的准备。

- [ ] 至少提供一段有适用范围、来源和专业审阅记录的完整练习
- [ ] 练习可以退出，允许反馈无变化或不适合，不以打卡或分数证明治疗效果
- [ ] 提供一般求助渠道说明与沟通准备单，区分一般支持和紧急支持
- [ ] 不将所有结果统一导向呼吸、外链文章或重新测评
- [ ] 自助内容证据、量表证据和网站效果验证分别记录

## 3. 非功能需求

### 3.1 国际化 (i18n)
**支持语言**:
| 代码 | 语言 |
|------|------|
| en | English (默认) |
| zh-hans | 简体中文 |
| zh-hant | 繁體中文 |
| es | Español |
| ja | 日本語 |
| ko | 한국어 |
| hi | हिन्दी |
| ar | العربية (RTL) |

**要求**:
- 全流程覆盖八种语言：入口、免责声明、结果、自助步骤、求助说明、无变化/不适、地区缺失与保存删除；不以英语回退视为完成
- 已开放语言须能完成整条路径，不只翻译菜单和按钮
- 问卷逐语言核验版本、来源和适用性；未核验版本不接入新流程，界面翻译不代表量表译本已经验证
- 语言切换即时生效
- 支持 RTL 布局（阿拉伯语）

### 3.2 隐私与安全
- 新流程的回答默认在浏览器内存处理，用户主动选择后才在本地保存或导出；现有自动保存逻辑需迁移
- 保存失败有明确反馈，支持删除；说明共用设备风险和清除浏览器数据后可能丢失
- 不创建账户，不使用广告追踪器
- 测评答案、分数及其他心理健康回答不得发送到服务器
- 托管与 CDN 服务商可能处理基础的匿名访问及性能数据；隐私页面必须如实披露
- 若启用产品分析，只允许收集不包含答案、分数、搜索内容或个人标识的汇总事件
- PHQ-9 第 9 题出现任何非零回答时，必须独立于总分显示安全提示及危机求助入口
- 安全提示不等于判断当前危险程度；不输出自杀/自伤风险预测或安全保证，求助不以完成量表为前提
- 回答、分数和关注方向不得写入 URL、页面标题、日志或统计事件

### 3.3 可访问性
- 语义化 HTML 结构
- 足够的颜色对比度
- 键盘可操作
- 屏幕阅读器友好

### 3.4 性能
- 首屏加载 < 3s (3G)
- Lighthouse 性能分数 > 90
- 静态生成，无需服务端运行

### 3.5 浏览器兼容性
- Chrome (最新两个版本)
- Firefox (最新两个版本)
- Safari (最新两个版本)
- Edge (最新两个版本)

## 5. 免责声明

Sunrain 是心理健康教育与自助辅助网站，不是医疗或心理诊疗机构。本工具仅提供症状初筛与信息参考，不能诊断、确认或排除任何心理疾病，也不能替代合格专业人士的评估、治疗或建议。请勿依据结果自行开始、停止或调整治疗。

若你正面临立即危险，请直接联系当地紧急服务或专业危机支持。本站不提供实时监护或紧急救援。

以上为待审阅文案。中英文完整草案与展示要求见 [免责声明文案草案](./MENTAL_HEALTH_CHECK_IN.md#7-八语免责声明文案草案)。免责声明须与评分、结果及实际支持能力一致。
