# Sunrain 八周执行计划

> 起始日期：2026-09-04

## 八周目标

在不上传心理健康回答、不引入广告追踪、不把危机支持付费化的前提下，验证两件事：

1. Sunrain 是否能让处于焦虑当下的用户快速进入一个可信、可完成的自助动作。
2. 学校、NGO 或员工支持机构是否愿意为可信部署、本地化和持续维护付费。

## 执行原则

- 内容负责被发现，短程工具负责产生价值，机构服务负责盈利。
- Cloudflare Web Analytics 负责流量、路径和性能基线；当前不建设自定义事件服务或分析数据库。
- 页面统计只能提供方向性路径信号，不等同于用户级漏斗或临床效果证据。
- 基线采集和产品准备并行，不能为了等待数据停工。
- 核心体验始终免费、无需注册，危机支持不参与任何商业转化。

## 阶段安排

| 阶段 | 时间 | 工作 | 完成标准 |
|---|---|---|---|
| 1. 流量基线 | 第 1 至 2 周 | 观察入口页、来源、地区、设备和 Core Web Vitals | 连续 14 天数据可用；能区分真实页面访问与边缘请求 |
| 2. 焦虑切片准备 | 第 1 至 2 周并行 | 完成流程、双语文案、安全检查、移动端和无障碍验证 | 不进入首页前已通过内部安全与体验检查 |
| 3. 单切片发布 | 第 3 周 | 首页只增加一个“我现在很焦虑”入口 | 入口、稳定动作、下一步三个页面路径均可观测 |
| 4. 传播验证 | 第 3 至 6 周 | 每周围绕一个焦虑场景制作文章、社区回答和短内容 | 每份外部内容只指向一个具体入口，可识别来源变化 |
| 5. 付费验证 | 第 4 至 8 周 | 访谈学校、NGO、员工支持与咨询机构，展示白标方案 | 完成 10 次有效访谈，争取至少 1 个付费试点 |
| 6. 决策 | 第 8 周 | 根据流量、路径表现、反馈和购买意愿做继续或停止判断 | 形成明确的继续、修正或暂停结论 |

如果首个 14 天窗口访问量不足以判断，不将其解释为产品失败；继续主动传播，但最长不因等待自然流量停工超过 28 天。

## “我现在很焦虑”第一版

第一版只回答“我现在很焦虑，先做什么”，不诊断、不承诺治愈、不提供开放式 AI 建议。

固定流程：

1. 先判断是否存在立即危险、严重身体症状或需要紧急帮助的情况，并提供危机支持出口。
2. 让用户选择更接近的当前体验：思绪停不下来、身体紧绷、呼吸急促、说不清但很难受。
3. 进入一个两分钟以内的稳定动作；优先复用现有呼吸和落地练习能力。
4. 动作结束后不询问疾病、创伤或自由文本，只提供继续练习、了解焦虑和寻求专业支持三个出口。

建议页面路径：

- `/anxiety/`：场景入口与安全分流。
- `/anxiety/steady/`：两分钟稳定动作。
- `/anxiety/next-step/`：完成动作后的下一步。

多语言版本沿用现有语言前缀。路径之间使用真实导航，以便现有 Cloudflare Web Analytics 观察各页面访问量；这些访问量不能去重为精确用户转化。

## 每周检查

每周只回答以下问题：

1. 哪些入口页和来源带来了真实访问？
2. 用户是否继续进入稳定动作和下一步页面？
3. 移动端性能或可访问性是否阻碍核心流程？
4. 是否出现错误引导、隐私承诺不一致或危机资源失效？
5. 本周证据支持继续、修正入口、修正动作，还是暂停该切片？

## 付费试点范围

免费核心体验不变。机构付费对象限定为：

- 独立品牌与域名部署。
- 机构本地资源和危机联系方式配置。
- 语言本地化、内容更新和可访问性维护。
- 匿名、聚合的页面与性能报告。
- 明确约定的内容审阅和响应时效。

不销售个人数据，不提供个人心理画像，不把测评分数作为销售线索。

## 第八周决策规则

- 流量不足：传播尚未验证，不判定产品无价值。
- 有入口访问、很少进入稳定动作：修正定位、文案和入口。
- 稳定动作页面有访问、下一步页面很少：修正动作长度与完成引导。
- 页面路径表现积极但没有重复使用证据：暂不扩充大量内容，先研究持续价值。
- 10 次有效机构访谈仍无试点意愿：暂停 B2B 产品化。
- 用户路径信号改善且获得付费试点：进入机构版本、报价和维护流程标准化。

## 暂不实施

- 自建 Worker + D1 行为统计管道。
- 用户账户、跨设备同步或心理档案。
- 广告、再营销像素或基于测评结果的推荐。
- 未经专业审阅的 AI 治疗建议。
- 在第一切片得到证据前同时扩张多个场景。
